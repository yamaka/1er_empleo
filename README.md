1. Requisitos:
   instalar nodejs  
   lo podemos descargar de la siguiente pagina  
   https://nodejs.org/en/download  
2. instalar gulp
   ejecutando el siguiente comando desde la terminal con el coamndo:    
   npm install -g gulp  
3. clonar el proyecto de git  con el siguiente comando:  
       git clone https://github.com/yamaka/1er_empleo.git  
4. clonar ingrear a la carpeta HTML y ejecutar el comando:  
   npm install  
5. ejecutar el comando y esperar que termine su ejecucion y automaticamente abrira en el navegador el proeycto: 
   npm run start  
6. si se necesita informacion adiccional con respecto al template la documentacion se encuentra en la raiz del proyecto dentro del directorio documentation
     index.html
